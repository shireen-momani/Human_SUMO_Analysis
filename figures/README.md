# Manuscript Figures – Visualisation Scripts

This folder contains Python and R scripts used to generate the figures for the manuscript. Each script reads pre-processed data and produces a figure (PDF/PNG).

---
## How to run

1. For scripts with an example_input/ folder, keep the folder in the same directory as the script.
2. Open a terminal and change into that directory:  

```bash
cd /path/to/folder
```

3.	Run the script directly. Output files will be written automatically into the output/ folder, created if it does not already exist:  


### Example for Python

``` bash
python aa_adjacent_sumo.py
```

### Example for R
``` bash
Rscript motif_heatmap_figure.R
```
